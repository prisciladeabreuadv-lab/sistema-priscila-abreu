Política de Privacidade

← Voltar

Última atualização: 31 de julho de 2026.

Esta Política de Privacidade descreve como o Sistema de Gestão Jurídica de Priscila Coutinho de Abreu de Oliveira ("o Sistema") trata os dados aos quais tem acesso.

1. Quem opera este sistema

O Sistema é operado por Priscila Coutinho de Abreu de Oliveira, advogada, para uso interno do próprio escritório. Contato: prisciladeabreu.adv@gmail.com.

2. Quais dados o Sistema armazena

O Sistema armazena, em banco de dados próprio (Supabase), os dados inseridos manualmente ou obtidos via integrações públicas para a gestão do escritório: dados de clientes, processos, prazos, tarefas, compromissos, publicações do DJEN e movimentações do DataJud (CNJ). Esses dados são acessíveis apenas pela usuária autenticada.

3. Uso da API do Google (Google Agenda)

Quando a usuária conecta sua conta Google, o Sistema solicita apenas o escopo https://www.googleapis.com/auth/calendar.events. Esse acesso é usado exclusivamente para criar eventos no Google Agenda da própria usuária, representando prazos de tarefas, prazos processuais e compromissos/audiências já cadastrados no Sistema.

O Sistema:

  • Não lê, importa ou copia eventos já existentes no Google Agenda da usuária;
  • Não compartilha, vende ou transfere os dados obtidos via Google com terceiros;
  • Não usa esses dados para publicidade, perfilamento ou qualquer finalidade além de manter a Agenda do escritório atualizada;
  • Não permite que desenvolvedores humanos leiam o conteúdo do Google Agenda da usuária.

O uso e a transferência de informações recebidas das APIs do Google por este aplicativo seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

4. Compartilhamento de dados

Os dados não são compartilhados com terceiros, exceto os provedores de infraestrutura estritamente necessários para o funcionamento do Sistema (hospedagem do banco de dados e do próprio site), que atuam apenas como processadores técnicos dos dados.

5. Segurança

O acesso ao Sistema é protegido por autenticação (login e senha) e por regras de segurança em nível de banco de dados, que restringem cada usuária aos seus próprios dados.

6. Retenção e exclusão

Os dados ficam armazenados enquanto o Sistema estiver em uso. A usuária pode solicitar a exclusão de qualquer dado, ou revogar o acesso à sua conta Google a qualquer momento, diretamente nas configurações de segurança da sua Conta Google (myaccount.google.com/permissions).

7. Contato

Dúvidas sobre esta política podem ser enviadas para prisciladeabreu.adv@gmail.com.
